# 휴숨 데이터 파이프라인

## 현재 앱에서 사용하는 데이터

### 통합대피소 API

주변 쉼터 목록, 위치, 운영 상태, 시설 정보를 가져와 지도 마커와 추천 카드에 반영합니다. 호출에 실패하면 앱에 포함된 기본 쉼터 데이터를 사용합니다.

### 기상 API

홈 화면의 현재 날씨, 현재 기온, 체감온도, 습도 표시에 사용합니다. API 키가 없거나 호출에 실패하면 기본값을 유지합니다.

기본값:

- 현재 날씨: 맑음
- 현재 기온: 34.2℃
- 체감온도: 37.6℃
- 습도: 68%
- 폭염 위험도: 높음

### 기상특보 API

폭염주의보 또는 폭염경보 발효 여부를 확인해 홈 화면의 폭염 위험 안내에 반영합니다. 특보 데이터가 없거나 호출에 실패하면 기존 폭염 위험도 표시를 유지합니다.

사용자 화면에는 API 실패, 인증 실패, 대체 데이터 사용 여부 같은 개발자용 표현을 표시하지 않습니다.

## CSV/XLSX 분석 결과

분석 탭은 현재 CSV/XLSX 기반 분석 결과를 사용합니다. 앱 화면의 주요 수치는 다음 값을 유지합니다.

- 분석 기간: 2020~2025년 여름철
- 최고 취약 지역: 대구 71.1점
- 총 온열질환자 수: 2,516명
- 최고기온 33℃ 이상 일수: 706일
- 최고기온-온열질환 상관관계: 0.4057
- 폭염일수 최다 지역: 대구 233일
- 고령인구 비율 최고 지역: 부산 25.3%

출처 표현:

- 기상청 ASOS 종관기상관측 데이터
- 질병관리청 온열질환 감시 데이터

## KOSIS API

KOSIS OpenAPI는 이번 MVP 앱에서 직접 호출하지 않습니다.

현재는 CSV 분석 결과를 사용하고, 실서비스에서는 취약계층 통계를 자동 갱신하기 위한 서버 측 데이터 수집 파이프라인으로 확장할 예정입니다. KOSIS API 키도 브라우저 번들에 노출되지 않도록 서버 또는 배치 작업 환경에서 관리해야 합니다.
