# 휴숨 데이터 파이프라인

## 앱 런타임 데이터

### 쉼터 추천 후보

홈 화면과 지도 화면의 추천 후보는 `ShelterDataContext`가 제공하는 `shelters` 배열입니다.

데이터 우선순위:

1. `EXPO_PUBLIC_SHELTER_API_KEY`가 있고 통합대피소 API 응답을 정상 파싱한 경우: API 응답을 앱의 쉼터 후보로 사용합니다.
2. API 키가 없거나 호출/파싱이 정상 처리되지 않은 경우: 앱에 포함된 기본 쉼터 데이터를 사용합니다.
3. 지역 선택이 되어 있으면 선택 지역에 맞는 쉼터만 필터링해 홈 추천 카드와 지도 마커에 전달합니다.

사용자 화면에는 데이터 전환 여부를 표시하지 않습니다.

### 기상 API

홈 화면의 현재 날씨, 현재 기온, 체감온도, 습도 표시에 사용합니다. API 키가 없거나 호출에 실패하면 선택 지역별 기본 날씨값을 사용합니다.

### 기상특보 API

폭염주의보 또는 폭염경보 발효 여부를 확인해 홈 화면의 폭염 위험 안내에 반영합니다. 특보 데이터가 없거나 호출에 실패하면 기존 위험도 표시를 유지합니다.

## CSV/XLSX 분석 결과

분석 탭은 현재 CSV/XLSX 기반 분석 결과를 사용합니다. 앱 화면의 주요 수치는 다음 값을 유지합니다.

- 분석 기간: 2020~2025년 여름철
- 최고 취약 지역: 대구 71.1점
- 총 온열질환자 수: 2,516명
- 최고기온 33℃ 이상 일수: 706일
- 최고기온-온열질환 상관관계: 0.4057
- 폭염일수 최다 지역: 대구 233일
- 고령인구 비율 최고 지역: 부산 25.3%

출처 표현:

- 기상청 ASOS 종관기상관측 데이터
- 질병관리청 온열질환 감시 데이터

## 무더위쉼터 CSV 사용 범위

`data-analysis` 폴더의 무더위쉼터 100개 CSV는 분석 보조 자료와 발표용 근거 수치에만 사용합니다.

이 CSV는 현재 앱의 홈/지도 추천 후보로 직접 로드되지 않습니다. 앱에서 실제 추천 후보로 사용하는 데이터는 통합대피소 API 응답 또는 기본 쉼터 데이터입니다.

## KOSIS API

KOSIS OpenAPI는 이번 MVP 앱에서 직접 호출하지 않습니다.

현재는 CSV 분석 결과를 사용하고, 실서비스에서는 취약계층 통계를 자동 갱신하기 위한 서버 측 데이터 수집 파이프라인으로 확장할 예정입니다. KOSIS API 키도 브라우저 번들에 노출되지 않도록 서버 또는 배치 작업 환경에서 관리해야 합니다.
