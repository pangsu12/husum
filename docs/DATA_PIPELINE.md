# 휴숨 데이터 파이프라인

## 역할 분리

CSV/XLSX는 과거 추세 분석용입니다. 온열질환자 수, 기온, 습도, 폭염일수, 고령인구 비율처럼 기간별·지역별 비교가 필요한 데이터를 정규화하고 집계합니다.

API는 현재 위치 기반 최신 정보 제공용입니다. 통합대피소 API는 지도 마커와 쉼터 추천 후보 생성에 활용할 예정이며, 네이버 지도 API와 기상 API는 앱 실행 시점의 위치와 위험 안내에 연결합니다.

## 지역별 종합 폭염 취약도

1. 대구: 71.1점
2. 서울: 48.63점
3. 대전: 39.73점
4. 광주: 33.04점
5. 부산: 24.21점

계산식은 기상 위험 35%, 폭염일수 25%, 온열질환 25%, 고령인구 비율 15%입니다. 각 항목은 지역별 값을 0~100 범위로 정규화했습니다.

## 현재 분석 흐름

1. `data-analysis/raw`의 CSV/XLSX 파일을 읽습니다.
2. 지역명을 서울, 대전, 대구, 부산, 광주로 표준화합니다.
3. 2020~2025년 여름철(6~9월) 데이터를 필터링합니다.
4. ASOS 기상, 온열질환, 폭염일수, 고령인구 비율을 지역별로 집계합니다.
5. 각 항목을 0~100점으로 정규화합니다.
6. 종합 폭염 취약도를 계산합니다.

## 쉼터 데이터 처리

무더위쉼터 CSV는 보조 분석으로만 사용했습니다.

- 무더위쉼터: 100개
- 총 수용인원: 2,773명
- 냉방기: 211대
- 선풍기: 209대

실제 앱의 최신 쉼터 위치와 추천 후보는 통합대피소 API 연동을 통해 생성할 예정입니다.

## 제외 및 확장 예정

`kosis_children.csv`와 `kosis_single_household.xlsx`는 현재 전국 단위 구조라 지역별 종합 위험도 계산에는 제외했습니다. 지역별 파일이 확보되면 어린이/유소년 비율과 1인가구 비율을 추가 취약계층 지표로 확장할 수 있습니다.

2026년은 진행 중 데이터라 이번 메인 분석에는 포함하지 않았습니다. 실제 서비스에서는 API와 DB를 연동해 최신 정보를 보완할 예정입니다.

## 앱 연결 계획

분석 결과는 앱 분석 탭에 반영됩니다. 위험도 분석은 홈 화면 위험도 카드, 지역별 위험 점수는 분석 탭 지역 순위, 통합대피소 API는 지도 마커와 쉼터 추천 후보 생성, 시민 제보는 쉼터 상태 보완에 연결됩니다.
